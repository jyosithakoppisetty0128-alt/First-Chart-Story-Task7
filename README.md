First Chart Story – Task 7

Project Overview

This project focuses on presenting data through visual charts and storytelling. It uses sample business data to understand monthly sales, expenses, and customer growth.

Objectives

- Visualize monthly sales performance.
- Track business expenses.
- Understand customer growth.
- Identify trends through charts.
- Present data insights in a simple and meaningful way.

Charts Created

- Monthly Sales – Bar Chart
- Monthly Expenses – Line Chart
- Monthly Customer Growth – Bar Chart

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab

Key Insights

- Sales increased from January to June.
- Expenses generally increased over the months.
- Customer numbers showed steady growth.
- Visual charts make business trends easier to understand.

Project Outcome

A PDF report containing three charts was created to present the data and business insights in a clear visual format.

Conclusion

This project demonstrates how data visualization can transform numerical data into meaningful insights. Charts help identify trends, understand business performance, and support better decision-making.

Note: The dataset used in this project is sample data created for educational purposes.
